# 🍉 合成大西瓜

基于 [Matter.js](https://brm.io/matter-js/) 物理引擎的合成类小游戏：相同数字的球相撞会合成更大的球，球堆持续越过红色警戒线即失败。

## 运行

无需构建、无依赖，任选其一：

- 直接用浏览器打开 `index.html`（file:// 协议即可运行）
- 或在项目目录运行 `python -m http.server`，然后访问 `http://localhost:8000`

## 玩法

- 移动鼠标（或手指）瞄准，点击落球
- 相同数字相撞合成更大一级的球（等级链 1~11，首次合成 11 级终极球会撒花）
- 球堆顶部持续越过红线 1.5 秒 → 游戏结束
- 按 **R** 或点击按钮重开；最高分保存在本地（localStorage）

## 功能

- **11 级合成链**：半径 17 → 138，得分按三角数递增（合成 n 级球得 n(n−1)/2 分）
- **自动落球**：侧栏按钮或按 **A** 键开关，挡位 1 秒 / 0.5 秒 / 0.2 秒 / 0.1 秒 / 0.05 秒 / 0.04 秒（自动落球不受手动冷却限制）
- **边框尺寸局内调整**：宽 360~720 × 长 520~900，步长 20px，调整后本局继续（不重开），越界的球会被自动收回容器

## 开发

纯原生 JS + Canvas 2D，无构建步骤。物理与规则核心（`sim.js`）不依赖 DOM，可在 Node 中直接测试：

```bash
node test.js     # 物理与游戏规则（26 条断言）
node smoke.js    # DOM 桩驱动渲染层跑帧（19 条断言）
node repro.js    # 物理巡检：三球摆法、随机对局、局内调边框压力测试（8 条断言）
```

## 代码结构

| 文件 | 职责 |
| --- | --- |
| `sim.js` | 无头物理/规则核心（Matter.js 封装，UMD：浏览器挂 `window.MiniSim`，Node 可 `require`） |
| `game.js` | Canvas 渲染与交互层（DPR 高清适配、合成动画、得分飘字、输入） |
| `index.html` | 页面结构与样式 |
| `matter.min.js` | Matter.js 物理引擎（第三方库） |
